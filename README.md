## 🎮 About the Game

Combolands: Roguelike Citybuilder is a single-player strategy roguelike developed and published by Crux Games. It released on August 24, 2026, for Windows. The game combines citybuilding, deckbuilding, card battler, and turn-based strategy elements as players develop procedural islands into thriving cities.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer provides optional quality-of-life and progression controls for Combolands. It can adjust city resources, improve building and card selection, support combo-focused runs, and unlock progression systems while preserving the game's core placement and synergy mechanics.

**Target Audience:** For players who want to experiment with building synergies, test guild combinations, explore procedural islands, access progression content sooner, or reduce the resource pressure of short roguelike runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Gold** — Keeps gold available for purchases, rerolls, dismissals, and other run-based decisions.
- **Free Rerolls** — Removes or reduces reroll costs when choosing buildings and other available options.
- **Unlimited Building Placement** — Allows buildings to be placed without normal placement restrictions during an active run.
- **Guaranteed Rare Options** — Improves the quality of building, blueprint, and heirloom choices presented during a run.
- **Unlimited Potions** — Prevents potion supplies from being consumed when manipulating the map or building behavior.
- **Max Combo Multiplier** — Maintains a high combo multiplier to support larger cascading effects from well-planned building layouts.
- **Freeze Run Resources** — Freezes selected run values so they remain available while experimenting with different city strategies.
- **Easy Building Testing** — Supports sandbox-style testing of building combinations, guild pairings, upgrades, and heirlooms.

### 📌 Progression

- **Instant Guild Unlocks** — Unlocks guild content without requiring the normal in-game progression thresholds.
- **Unlock All Councillors** — Makes the available city councillors accessible for runs without completing their normal unlock requirements.
- **Max Rank Access** — Unlocks the higher challenge ranks for players who want to access the full difficulty range immediately.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combolands is a turn-based citybuilder rather than a character-driven exploration game. There is no conventional player movement system. Use the trainer after loading a run and selecting the island, guilds, or available building options you want to test.

### Tools & Inventory

The game presents buildings, blueprints, heirlooms, upgrades, potions, gold, and councillor-related progression as run resources. Activate resource options before spending gold or using consumable items. Unlimited Potions and Guaranteed Rare Options are best used when testing map manipulation, building upgrades, and unusual combinations.

### World & Environment

Each run begins on a procedurally generated island. Choose two guilds, place buildings, expand the settlement, and arrange structures to create synergies and cascading combos. Unlimited Building Placement is useful for testing spatial layouts, while Max Combo Multiplier helps evaluate high-value interactions without restarting repeatedly.

### Combat & Weapons

Combolands has no conventional combat system, enemy encounters, weapons, or combat statistics. Progression is based on city construction, resource management, building interactions, guild combinations, councillors, and challenge ranks. Combat-related trainer options are therefore not applicable.
